Política de Privacidade — Meu Carrinho de Compras

Última atualização: 14 de junho de 2026

Esta política de privacidade descreve como o aplicativo "Meu Carrinho de Compras" coleta, usa e protege suas informações.

1. Dados que coletamos

O aplicativo não coleta, armazena ou transmite dados pessoais identificáveis. Os únicos dados armazenados são:

- Nome do mercado (digitado pelo usuário)
- Orçamento definido (digitado pelo usuário)
- Lista de produtos com nome, preço e quantidade (digitados pelo usuário)

Esses dados são armazenados exclusivamente no dispositivo do usuário, por meio do AsyncStorage (armazenamento local do Android/iOS), e não são enviados para servidores externos.

2. Como usamos os dados

Os dados são usados apenas para:

- Exibir a lista de compras na tela
- Calcular o total gasto e o saldo restante
- Persistir as informações entre sessões do app

3. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos dados para terceiros. O aplicativo funciona 100% offline e não possui integração com serviços externos.

4. Segurança dos dados

Como os dados ficam apenas no dispositivo do usuário, a segurança depende da proteção do próprio dispositivo (senha, biometria, etc.). Recomendamos manter o dispositivo protegido.

5. Crianças

O aplicativo não é direcionado a menores de 13 anos. Não coletamos dados intencionalmente de crianças.

6. Alterações nesta política

Podemos atualizar esta política ocasionalmente. Recomendamos revisar esta página periodicamente.

7. Contato

Para dúvidas sobre esta política de privacidade, entre em contato pelo e-mail: brunoferreirasalustiano@gmail.com

8. Permissões do aplicativo

O aplicativo não solicita permissões de câmera, microfone, localização, contatos ou acesso à internet. A única permissão utilizada é o acesso ao armazenamento local do dispositivo para salvar a lista de compras.
