🛒 Política de Privacidade

Meu Carrinho de Compras — Última atualização: 14 de junho de 2026

Resumo rápido: Este app não coleta dados pessoais. Todos os dados (lista de compras, orçamento e nome do mercado) ficam apenas no seu celular e não são enviados para a internet.

1. Dados que coletamos

O aplicativo não coleta, armazena ou transmite dados pessoais identificáveis. Os únicos dados armazenados são:

  • Nome do mercado (digitado por você)
  • Orçamento definido (digitado por você)
  • Lista de produtos com nome, preço e quantidade (digitados por você)

Esses dados são armazenados exclusivamente no dispositivo, por meio do AsyncStorage (armazenamento local do Android/iOS), e não são enviados para servidores externos.

2. Como usamos os dados

Os dados são usados apenas para:

  • Exibir a lista de compras na tela
  • Calcular o total gasto e o saldo restante
  • Manter suas informações salvas entre as sessões do app

3. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos dados para terceiros. O aplicativo funciona 100% offline e não possui integração com serviços externos, analytics, publicidade ou redes sociais.

4. Segurança dos dados

Como os dados ficam apenas no dispositivo, a segurança depende da proteção do próprio celular (senha, biometria, etc.). Recomendamos manter o dispositivo protegido.

5. Crianças

O aplicativo não é direcionado a menores de 13 anos. Não coletamos dados intencionalmente de crianças.

6. Alterações nesta política

Podemos atualizar esta política ocasionalmente. Recomendamos revisar esta página periodicamente. Notificaremos sobre mudanças significativas dentro do app.

8. Permissões do aplicativo

O aplicativo não solicita permissões de câmera, microfone, localização, contatos ou acesso à internet. A única funcionalidade utilizada é o armazenamento local do dispositivo para salvar a lista de compras.
